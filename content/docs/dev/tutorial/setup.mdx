Create the provider module in its own directory (or clone the [example repo](https://github.com/Aelysium-Group/rcm-smart-mock) and follow along):

```bash
mkdir rcs-example
cd rcs-example
mkdir -p src/main/java/fun/democraft/smart/example
mkdir -p src/main/resources
```

**`settings.gradle`**

```groovy
rootProject.name = 'rcs-example'
```

**`gradle.properties`**

```properties
module_version          = 0.1.0
rustyconnector_version  = 0.9.3
archives_base_name      = rcs-example
```

**`build.gradle`** — same shape as the other `rcm-*` modules. Core and Adventure are `compileOnly` (they live in the runtime parent classloader, never shade them):

```groovy
plugins {
    id 'java-library'
    id 'com.gradleup.shadow' version '9.0.0-beta4'
}

group = 'fun.democraft'
version = module_version

repositories {
    mavenCentral()
    maven { url = 'https://java.funa.dev/snapshots/' }
    maven {
        name = "funaReleases"
        url = uri("https://java.funa.dev/releases")
    }
}

dependencies {
    compileOnly "group.aelysium.rustyconnector:core:${rustyconnector_version}"
    compileOnly 'net.kyori:adventure-api:4.17.0'
    implementation("fun.democraft:smart:2.0.0")
}

java.toolchain.languageVersion = JavaLanguageVersion.of(21)
tasks.withType(JavaCompile).configureEach { options.encoding = 'UTF-8' }
jar.enabled = false
shadowJar {
    archiveBaseName.set(archives_base_name)
    archiveClassifier.set('')
    dependencies {
        // RustyConnector loads Smart as a separate module.
        exclude(dependency('fun.democraft:smart:.*'))
    }
}
assemble.dependsOn shadowJar
```

Gradle resolves Smart 2.0.0 from the Funa releases repository. Install the Smart module alongside the mock on the proxy.
