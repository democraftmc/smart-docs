In this tutorial you will build a complete custom Smart provider from scratch: **`mock`**, a provider that "provisions" servers without touching any real API — perfect for learning and for tests.

A finished, working version of everything built here lives in the example repo [`rcs-example`](https://github.com/Aelysium-Group/rcm-smart-mock) — clone it to follow along or as a starting point.

By the end you will have:

- a native module `rcs-example` that compiles to a jar,
- a provider config file `rustyconnector/smart/providers/mock.yml`,
- a working `SmartProvider` implementation registered into the Smart core,
- family metadata wired up so the provider knows what to "create".
